# Share Note

## Status

Implemented (incorrectly) — requires rework per this spec.

## Problem

The current implementation shares a note via a direct toggle on the `🔗` emoji button with no modal, no copy affordance, and no explicit stop-sharing action. The URL appears inline as a truncated link in the toolbar. This diverges from the intended UX.

## Expected UX

Clicking the share button opens a **Share Note modal**. The modal handles the full lifecycle: generating the link, copying it, and stopping sharing. The header shows a labelled "Shared" button when the note is already public.

### Share Note modal (note not yet shared)

On open, the modal immediately calls `POST /api/notes/{id}/share` to generate the link, then shows it.

```
┌─────────────────────────────────────────┐
│  Share Note                             │
│                                         │
│  Anyone with this link can view this    │
│  note:                                  │
│                                         │
│  ┌────────────────────────┐ ┌────────┐  │
│  │ https://…/shared/f5b4… │ │  Copy  │  │
│  └────────────────────────┘ └────────┘  │
│                                         │
│  Stop sharing               Close       │
└─────────────────────────────────────────┘
```

### Share Note modal (note already shared)

Same layout; no API call needed on open — URL is pre-populated from note state.

### Header button states

| Note state | Button shown |
|---|---|
| Not shared | `🔗` icon only (gray) |
| Shared | `🔗 Shared` labelled button (green-tinted) |

## Acceptance Criteria

| # | Behaviour |
|---|---|
| 1 | Clicking share opens the modal; does **not** immediately toggle sharing |
| 2 | If note is not yet shared, modal calls `POST /api/notes/{id}/share` on open and shows the returned URL |
| 3 | If note is already shared, modal pre-populates the URL from `note.public_slug` — no extra API call |
| 4 | URL field is read-only |
| 5 | "Copy" button copies the full absolute URL to clipboard and briefly shows "Copied!" feedback |
| 6 | "Stop sharing" calls `DELETE /api/notes/{id}/share`, clears the link, and closes the modal |
| 7 | "Close" dismisses the modal without changing share state |
| 8 | Header shows a labelled `🔗 Shared` button (green) when `is_public = true` |
| 9 | Public note URL path is `/shared/{slug}` — consistent between API response and the view route |
| 10 | The `👥` collaborators button is removed until the feature is implemented |

## URL Format

```
/shared/{public_slug}
```

`public_slug` is the existing 8-character random string generated by `generateSlug()` in the share route. No change to generation logic needed — only the path prefix changes.
